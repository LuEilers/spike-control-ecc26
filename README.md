# spike-control-ecc26
Code and simulation results for the paper "On the stability of event-based control with neuronal dynamics" published at 2026 European Control Conference (ECC)

## Content
The code to produce the figures of the [paper published at the ECC](https://ieeexplore.ieee.org/abstract/document/11625541) can be found in [fig2.ipynb](notebooks/fig2.ipynb) and [fig3.ipynb](notebooks/fig3.ipynb). The code to produce the additional figures of the [arXiv preprint](https://arxiv.org/pdf/2511.18015) can be found in [fig2a.ipynb](notebooks/fig2a.ipynb) and [fig2b.ipynb](notebooks/fig2b.ipynb).

## Requirements
The code was executed with Python 3.13.7 and the following packages are required:
- numpy
- matplotlib
- sys
- mpl_toolkits.axes_grid1
- json
- warnings
